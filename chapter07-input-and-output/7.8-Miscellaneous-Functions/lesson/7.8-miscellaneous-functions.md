# 7.8 - Miscellaneous Functions

## Big idea

A guided tour of the standard library's everyday tools — the ones real programs lean on constantly. Headers: `<string.h>`, `<ctype.h>`, `<stdlib.h>`, `<math.h>`.

---

## 7.8.1 String operations (<string.h>)

s, t = char*; c, n = ints:

| Call | Does |
|---|---|
| `strcat(s,t)` | append t to end of s |
| `strncat(s,t,n)` | append at most n chars of t |
| `strcmp(s,t)` | <0, 0, >0 for s <,==,> t |
| `strncmp(s,t,n)` | compare first n chars |
| `strcpy(s,t)` | copy t into s |
| `strncpy(s,t,n)` | copy at most n chars (may not '\0'-terminate!) |
| `strlen(s)` | length, excluding '\0' |
| `strchr(s,c)` | pointer to FIRST c in s, or NULL |
| `strrchr(s,c)` | pointer to LAST c in s, or NULL |

You implemented several of these in Chapter 5 — now use the real ones. Caller must ensure destination space for cat/cpy!

## 7.8.2 Character testing (<ctype.h>)

| Call | True for |
|---|---|
| `isalpha(c)` | letters |
| `isupper(c)` / `islower(c)` | case tests |
| `isdigit(c)` | 0-9 |
| `isalnum(c)` | isalpha or isdigit |
| `isspace(c)` | blank, tab, newline, CR, FF, vertical tab |
| `toupper(c)` / `tolower(c)` | converted char |

---

## 7.8.3 ungetc

```c
int ungetc(int c, FILE *fp);
```

Push ONE character back onto a stream — the library version of your Chapter 4 `ungetch`. One char of pushback guaranteed. Note arg order: char first, stream second.

---

## 7.8.4 Command execution

```c
system("date");        /* run a shell command from inside your program */
```

Return value is system-dependent; useful, but a security foot-gun with untrusted input.

---

## 7.8.5 Storage management

```c
void *malloc(size_t n);           /* uninitialized n bytes, or NULL   */
void *calloc(size_t n, size_t s); /* n objects of size s, ZEROED      */
void free(void *p);
```

- cast the result to the target type: `ip = (int *) calloc(n, sizeof(int));`
- check for NULL!
- free only pointers that came from malloc/calloc; **never use after free**; freeing in random order is fine, but never twice

---

## 7.8.6 Mathematical functions (<math.h>)

All take/return double: `sin cos atan2 exp log log10 pow(x,y) sqrt fabs`.
Compile with `-lm` on Linux.

---

## 7.8.7 Random numbers

```c
#define frand() ((double) rand() / (RAND_MAX + 1.0))   /* [0,1) */

srand(seed);      /* set the sequence's start */
rand();           /* 0 .. RAND_MAX            */
```

Same seed ⇒ same sequence (great for reproducible tests). Common idiom for a die: `rand() % 6 + 1` (slightly biased; fine for now).
