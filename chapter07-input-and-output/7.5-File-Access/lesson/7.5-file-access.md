# 7.5 - File Access

## Big idea

Everything so far read stdin/wrote stdout. Now: open **named files** yourself.

```c
FILE *fp;
FILE *fopen(char *name, char *mode);

fp = fopen("data.txt", "r");
```

`FILE *` is a **file pointer** — it refers to a structure holding everything the library needs (buffer, position, flags...). You don't look inside; you hand it to I/O functions. (Chapter 8 reveals the internals!)

---

## fopen modes

| Mode | Meaning |
|---|---|
| `"r"` | read; file must exist |
| `"w"` | write; **truncates** existing content or creates |
| `"a"` | append; writes go to the end; creates if absent |

fopen returns **NULL on failure** (no permission, missing file for "r"...). ALWAYS check:

```c
if ((fp = fopen(name, "r")) == NULL) {
    printf("can't open %s\n", name);
    exit(1);
}
```

---

## Character I/O on files

```c
int getc(FILE *fp);        /* next char from fp, or EOF */
int putc(int c, FILE *fp); /* write c to fp             */
```

And the familiar names are just special cases:

```c
#define getchar()   getc(stdin)
#define putchar(c)  putc((c), stdout)
```

`stdin`, `stdout`, `stderr` are pre-opened FILE* constants.

---

## Formatted file I/O

```c
int fscanf(FILE *fp, char *format, ...);
int fprintf(FILE *fp, char *format, ...);
```

Exactly scanf/printf with an explicit stream first.

---

## The book's cat (file concatenation)

```c
#include <stdio.h>

main(int argc, char *argv[])       /* cat: concatenate files */
{
    FILE *fp;
    void filecopy(FILE *, FILE *);

    if (argc == 1)                  /* no args: copy stdin */
        filecopy(stdin, stdout);
    else
        while (--argc > 0)
            if ((fp = fopen(*++argv, "r")) == NULL) {
                printf("cat: can't open %s\n", *argv);
                return 1;
            } else {
                filecopy(fp, stdout);
                fclose(fp);
            }
    return 0;
}

void filecopy(FILE *ifp, FILE *ofp)
{
    int c;

    while ((c = getc(ifp)) != EOF)
        putc(c, ofp);
}
```

Pattern notes:

- **no args ⇒ act as a filter** (stdin→stdout) — Unix convention
- open, use, **fclose** each file
- filecopy takes streams, not names — reusable for any pair

---

## fclose

```c
int fclose(FILE *fp);
```

Why bother (programs exiting close files anyway)?

1. OS limits on simultaneously open files
2. **flushes buffered output** to disk — unclosed output files can lose tail data
3. frees the FILE slot for reuse

## Summary table

| Concept | Syntax |
|---|---|
| Open | `fp = fopen(name, "r"/"w"/"a")` |
| Check | `if (fp == NULL) ...` |
| Char I/O | `getc(fp)`, `putc(c, fp)` |
| Formatted | `fprintf(fp,...)`, `fscanf(fp,...)` |
| Std streams | stdin, stdout, stderr (already open) |
| getchar | = getc(stdin) |
| Close | `fclose(fp)` — flushes output |
| "w" hazard | truncates instantly |
