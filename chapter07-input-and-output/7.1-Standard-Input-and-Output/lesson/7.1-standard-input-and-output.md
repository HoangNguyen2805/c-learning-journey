# 7.1 - Standard Input and Output

## Big idea

The C library gives every program a simple I/O model: a **text stream** in, a text stream out.

```text
stdin  -> your program -> stdout
```

- `getchar()` reads the next character from stdin (returns `EOF` at end)
- `putchar(c)` writes character c to stdout

You've used these since Chapter 1 — this section formalizes them and adds redirection.

---

## Redirection: the shell superpower

Your program always reads stdin/writes stdout. The SHELL rewires where those go:

```bash
./prog < infile        # stdin comes from infile
./prog > outfile       # stdout goes to outfile
./prog < in > out      # both
otherprog | ./prog     # stdin = otherprog's output (a pipe)
./prog | wc -l         # your output feeds wc
```

The program's code never changes — it just reads getchar and writes putchar. The strings `<infile` and `>outfile` are NOT in argv; the shell eats them.

---

## Text streams and lines

A text stream = sequence of lines, each ending `'\n'`. The library converts between this model and whatever the OS really uses (e.g. `\r\n` on Windows).

---

## getchar returns int — still true, still vital

```c
int c;                    /* NOT char */
while ((c = getchar()) != EOF)
    putchar(c);
```

EOF must be distinguishable from every valid character, so it's an out-of-band int value (typically -1). Storing into char breaks the comparison.

---

## printf belongs here too

`printf` writes to stdout as well — putchar and printf calls interleave in order:

```c
putchar('A');
printf(" and %d\n", 42);     /* output: A and 42 */
```

---

## Example: lowercase filter

```c
#include <stdio.h>
#include <ctype.h>

int main(void)             /* lower: convert input to lower case */
{
    int c;

    while ((c = getchar()) != EOF)
        putchar(tolower(c));
    return 0;
}
```

With `<ctype.h>` (`isalpha`, `isdigit`, `isspace`, `tolower`, `toupper`...) your filters work regardless of character set.

---

## The filter pattern

Dozens of Unix tools are exactly this shape:

```text
while ((c = getchar()) != EOF)
    transform and/or putchar
```

Chain them with pipes and small tools compose into big jobs. This is the Unix philosophy in four lines.

## Summary table

| Concept | Meaning |
|---|---|
| stdin/stdout | default text streams |
| `getchar()` | next char or EOF (int!) |
| `putchar(c)` | write char to stdout |
| `< file` | shell: stdin from file |
| `> file` | shell: stdout to file |
| `a | b` | pipe a's output into b |
| `<ctype.h>` | portable char tests/conversions |
| Filter | read-transform-write loop |
