# 7.2 - Formatted Output - printf

## Big idea

`printf` converts internal values to text under control of a **format string**:

```c
int printf(char *format, arg1, arg2, ...);
```

It returns the number of characters written (rarely used, but true).

---

## Anatomy of a conversion spec

Between `%` and the conversion character, IN ORDER, all optional:

```text
%  [flags]  [width]  [.precision]  [h|l]  conversion
```

| Part | Meaning |
|---|---|
| `-` | left-justify in the field |
| `+` | always print sign |
| ` ` (space) | space where + would be |
| `0` | pad with zeros |
| `#` | alternate form (0x for hex, etc.) |
| width | MINIMUM field width |
| .precision | strings: max chars; floats: digits after point; ints: min digits |
| `h` / `l` | short / long argument |

---

## Conversion characters

| Char | Prints | Char | Prints |
|---|---|---|---|
| `%d,%i` | int decimal | `%f` | double `[-]mmm.dddddd` |
| `%o` | octal | `%e,%E` | scientific |
| `%x,%X` | hex | `%g,%G` | shorter of %e/%f |
| `%u` | unsigned | `%s` | string until '\0' or precision |
| `%c` | single char | `%p` | pointer |
| `%%` | literal % | | |

Unsupported/wrong specs = undefined garbage. The format must match argument types — printf can't check for you (compilers warn; heed them).

---

## Width and precision at work (book's "hello, world" table)

```c
printf(":%s:",      "hello, world");   /* :hello, world:        */
printf(":%10s:",    "hello, world");   /* :hello, world:        */
printf(":%.10s:",   "hello, world");   /* :hello, wor:          */
printf(":%-10s:",   "hello, world");   /* :hello, world:        */
printf(":%.15s:",   "hello, world");   /* :hello, world:        */
printf(":%-15s:",   "hello, world");   /* :hello, world   :     */
printf(":%15.10s:", "hello, world");   /* :     hello, wor:     */
printf(":%-15.10s:","hello, world");   /* :hello, wor     :     */
```

Read `%15.10s`: at most 10 chars of the string, right-justified in 15 columns.

---

## Star: runtime width/precision

```c
printf("%.*s", maxlen, s);      /* precision comes from variable maxlen */
printf("%*d", width, n);        /* width from a variable */
```

---

## %s danger

```c
printf(s);          /* WRONG if s contains a %  -> chaos  */
printf("%s", s);    /* always safe                        */
```

This is a real security-bug class (format string vulnerabilities).

---

## sprintf: printf into a string

```c
int sprintf(char *string, char *format, arg1, ...);
```

Formats into `string` (caller must ensure it's big enough!) instead of stdout.

---

## Summary table

| Concept | Example |
|---|---|
| Min width | `%10d` |
| Left justify | `%-10d` |
| Zero pad | `%06.2f` → `003.14` |
| String cap | `%.8s` |
| Both | `%15.10s` |
| Runtime | `%*d`, `%.*s` |
| Long/short | `%ld`, `%hd` |
| Safe string print | `printf("%s", s)` never `printf(s)` |
| To a buffer | `sprintf(buf, fmt, ...)` |
