# 7.4 - Formatted Input - Scanf

## Big idea

`scanf` is printf's inverse — it reads characters, matches them against a format, and stores converted values **through pointers**:

```c
int scanf(char *format, ...);
```

```c
int n;
double x;
scanf("%d %lf", &n, &x);     /* AMPERSANDS! scanf needs addresses */
```

Returns: number of items successfully converted, or `EOF` at end of input.

---

## The & rule

scanf must MODIFY your variables, so it needs their addresses:

```c
scanf("%d", &n);      /* right                              */
scanf("%d", n);       /* WRONG: passes n's value as address */
scanf("%s", name);    /* right IF name is an array (already a pointer) */
```

Forgetting & is THE classic scanf bug — often crashes at runtime, compiles fine (though gcc warns).

---

## Format string contents

1. **Whitespace in the format**: matches ANY amount of input whitespace (including none)
2. **Ordinary characters**: must match the next input character exactly
3. **Conversion specs**: `%`, optional `*` (suppress), optional width, conversion char

Most numeric conversions skip leading whitespace automatically. `%c` does NOT — it reads the very next char, even a blank.

---

## Conversions

| Spec | Reads | Argument type |
|---|---|---|
| `%d` | decimal int | `int *` |
| `%i` | int, accepts 0x.. and 0.. | `int *` |
| `%o`, `%x` | octal / hex | `int *` |
| `%u` | unsigned | `unsigned *` |
| `%c` | one char (no space skip) | `char *` |
| `%s` | word (up to whitespace), adds '\0' | `char *` (array, no &) |
| `%e,%f,%g` | float | `float *` |
| `%lf` | double | `double *` — the l is REQUIRED |

`h` for short (`%hd`), `l` for long (`%ld`) and double (`%lf`). **printf `%f` takes double; scanf `%f` takes float** — asymmetric because of promotions!

---

## Check the return value

```c
if (scanf("%d", &n) != 1) {
    /* input wasn't a number - handle it! */
}
```

The book's calculator loop:

```c
while (scanf("%lf", &v) == 1)
    printf("\t%.2f\n", sum += v);
```

On bad input scanf returns 0 AND leaves the offending characters unread — an infinite loop if you don't consume them.

---

## Literal matching & assignment suppression

Parse dates like `25/12/2025`:

```c
scanf("%d/%d/%d", &d, &m, &y);      /* slashes matched literally */
```

Skip a field with `*`:

```c
scanf("%*s %d", &n);     /* read+discard a word, keep the int */
```

---

## Mixed line/field input: the sscanf pattern

Reading whole lines then parsing them is more robust:

```c
while (mygetline(line, sizeof line) > 0) {
    if (sscanf(line, "%d %s", &n, word) == 2)
        ...
}
```

`sscanf` runs scanf's matcher over a STRING. Bad line? Just read the next one — no stuck input stream.

---

## Summary table

| Concept | Rule |
|---|---|
| Arguments | pointers — use & (arrays exempt) |
| Return | count converted; EOF at end |
| Format whitespace | matches any/none input whitespace |
| %c | no whitespace skipping |
| %s | one word, appends '\0' |
| double | `%lf` in scanf, `%f` in printf |
| `%*d` | parse but discard |
| Robust pattern | mygetline + sscanf |
