# 7.7 - Line Input and Output

## Big idea

The library's line-at-a-time tools:

```c
char *fgets(char *line, int maxline, FILE *fp);
int   fputs(char *line, FILE *fp);
```

Plus the stdout/stdin-specific cousins `gets`/`puts` — with a serious warning.

---

## fgets

```c
fgets(line, MAXLINE, fp)
```

- reads at most `maxline-1` characters into `line`
- **keeps the '\n'** if one was read
- always '\0'-terminates
- returns `line` on success, **NULL on end of file or error**

Canonical loop:

```c
while (fgets(line, MAXLINE, stdin) != NULL)
    process(line);
```

A too-long input line simply arrives in pieces — no overflow. That bounded size is the whole point.

---

## fputs

```c
fputs(line, fp)
```

- writes the string to fp
- does **NOT** add a newline (symmetric with fgets keeping it)
- returns EOF on error, non-negative otherwise

fgets+fputs round-trip a file byte-perfectly.

---

## gets/puts: know them, avoid gets

```c
gets(line)     /* reads a line, DELETES the '\n'  - NO SIZE LIMIT: dangerous */
puts(line)     /* writes line and ADDS a '\n'                                */
```

`gets` cannot be told the buffer size ⇒ any long line overflows memory. It's the canonical security hole (removed from modern C). **Use fgets(line, size, stdin).** `puts` is fine for whole lines.

Note the asymmetries: gets strips '\n', puts adds one; fgets keeps it, fputs doesn't touch it.

---

## The book's implementations (instructive!)

```c
/* fgets: get at most n chars from iop */
char *fgets(char *s, int n, FILE *iop)
{
    register int c;
    register char *cs;

    cs = s;
    while (--n > 0 && (c = getc(iop)) != EOF)
        if ((*cs++ = c) == '\n')
            break;
    *cs = '\0';
    return (c == EOF && cs == s) ? NULL : s;
}

/* fputs: put string s on file iop */
int fputs(char *s, FILE *iop)
{
    int c;

    while ((c = *s++))
        putc(c, iop);
    return ferror(iop) ? EOF : 0;
}
```

Both are just getc/putc loops — the standard library isn't magic.

---

## getline built from fgets (book)

```c
int mygetline(char *line, int max)
{
    if (fgets(line, max, stdin) == NULL)
        return 0;
    else
        return strlen(line);
}
```

## Choosing input granularity

```text
getc      - chars:  filters, scanners
fgets     - lines:  line-oriented tools, robust parsing (with sscanf)
fscanf    - fields: rigid formats, fragile on errors
```

---

## Summary table

| Function | Newline behavior | Safety |
|---|---|---|
| `fgets(s,n,fp)` | keeps '\n' | bounded — safe |
| `fputs(s,fp)` | adds nothing | safe |
| `gets(s)` | strips '\n' | UNBOUNDED — never use |
| `puts(s)` | adds '\n' | safe |
| fgets returns | NULL at EOF/error | check it |
| fputs returns | EOF on error | rarely checked |
