# 6.1 - Basics of Structures

## Big idea

Arrays hold many values of ONE type. A **structure** groups values of DIFFERENT types under one name:

```c
struct point {
    int x;
    int y;
};
```

A point isn't just two loose ints — it's one **thing** with two named parts (members).

---

## Declaring and defining

```c
struct point {          /* declares the SHAPE (no memory yet)     */
    int x;
    int y;
};

struct point pt;        /* defines a VARIABLE of that shape       */
struct point maxpt = { 320, 200 };   /* with initializers         */
```

`struct point` together is the type name. The tag `point` lets you refer to the shape later.

---

## Accessing members: the dot

```c
pt.x = 10;
pt.y = 20;
printf("(%d,%d)\n", pt.x, pt.y);

double dist = sqrt((double)pt.x * pt.x + (double)pt.y * pt.y);
```

`structure.member` — works for reading and writing.

---

## Structures can nest

```c
struct rect {
    struct point pt1;    /* lower-left  */
    struct point pt2;    /* upper-right */
};

struct rect screen;
screen.pt1.x = 0;        /* chain the dots */
```

---

## Three ways to combine declaration forms

```c
struct point { int x; int y; };          /* tag only, use later    */
struct point { int x; int y; } a, b;     /* tag + variables now    */
struct { int x; int y; } single;         /* no tag: one-off shape  */
```

---

## What CAN you do with a whole structure?

Legal operations on a structure as a unit:

```text
1. copy / assign it            (b = a;)
2. take its address            (&a)
3. access its members          (a.x)
4. pass to / return from functions  (details in 6.2)
```

NOT legal: comparing with `==`. You must compare member by member.

---

## Assignment copies EVERYTHING

```c
struct point a = { 1, 2 };
struct point b = a;      /* b gets its own copies of x and y */
b.x = 99;                /* a.x is still 1                   */
```

This is a real copy — unlike arrays, which you can't assign at all.

---

## Common mistakes

```c
struct point { int x; int y; }    /* forgot the semicolon -> chaos below */

if (a == b)                        /* WRONG: no == for structs           */

struct point p; p = { 3, 4 };      /* WRONG: {} only at initialization   */
```

---

## Summary table

| Concept | Syntax |
|---|---|
| Declare shape | `struct point { int x; int y; };` |
| Define variable | `struct point pt;` |
| Initialize | `struct point pt = { 3, 4 };` |
| Member access | `pt.x` |
| Nested access | `screen.pt1.x` |
| Copy | `b = a;` (member-wise copy) |
| Compare | member by member — never `==` |
| Tagless struct | `struct { ... } var;` (one-off) |
