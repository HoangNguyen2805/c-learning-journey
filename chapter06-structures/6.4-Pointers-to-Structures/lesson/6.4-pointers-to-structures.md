# 6.4 - Pointers to Structures

## Big idea

K&R rewrites the keyword counter with **pointers instead of indices**. Instead of `keytab[mid]`, we walk with `struct key *p`. This section is where struct pointers + pointer arithmetic combine.

---

## Binary search, pointer edition

```c
struct key *binsearch(char *word, struct key *tab, int n)
{
    int cond;
    struct key *low  = &tab[0];
    struct key *high = &tab[n];       /* one past the end */
    struct key *mid;

    while (low < high) {
        mid = low + (high - low) / 2;
        if ((cond = strcmp(word, mid->word)) < 0)
            high = mid;
        else if (cond > 0)
            low = mid + 1;
        else
            return mid;
    }
    return NULL;      /* not found */
}
```

Changes from the index version:

```text
returns struct key *   (or NULL) instead of an index
low/high/mid are POINTERS into the table
found row: p->count++ instead of keytab[i].count++
```

---

## Why `mid = low + (high-low)/2`?

You may NOT add two pointers — `(low+high)/2` is illegal. But you MAY:

- subtract pointers → element count between them: `high - low`
- add int to pointer: `low + count/2`

So the midpoint is written as an offset from `low`.

---

## The one-past-the-end rule

`&tab[n]` doesn't point at a real element, but C **guarantees** this address is valid for arithmetic and comparison (just never dereference it). The loop `while (low < high)` with `high = mid` uses a half-open range `[low, high)` — a pattern you'll see everywhere in real C.

---

## Pointer arithmetic scales by struct size

```c
struct key *p = keytab;
p++;              /* advances sizeof(struct key) BYTES, one full row */
```

The compiler does the scaling. `high - low` likewise counts **structs**, not bytes.

---

## Iterating a struct table with pointers

```c
for (p = keytab; p < keytab + NKEYS; p++)
    if (p->count > 0)
        printf("%4d %s\n", p->count, p->word);
```

Compare with the index loop — same work, different idiom.

---

## Precedence review (again — it matters)

```c
++p->count        ++(p->count)   increment the count member
(++p)->count      advance p, THEN read count
(p++)->count      read count, THEN advance p
*p->word          first char of the word
*p->word++        char, then advance word pointer
(*p->word)++      increment that char
*p++->word        char, then advance p
```

---

## Struct size ≠ member sum (repeat warning)

Alignment padding means `sizeof(struct key)` may be 16 when members total 12. Use `sizeof` for all allocation and arithmetic.

---

## Summary table

| Concept | Pointer idiom |
|---|---|
| Not-found result | return `NULL` |
| Midpoint | `low + (high-low)/2` |
| End marker | `&tab[n]`, compare only |
| Half-open loop | `while (low < high)` |
| Walk table | `for (p = tab; p < tab+n; p++)` |
| Member via pointer | `p->count`, `p->word` |
| `p++` step size | one whole struct |
