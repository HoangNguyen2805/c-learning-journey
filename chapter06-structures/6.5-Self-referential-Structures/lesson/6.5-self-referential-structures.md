# 6.5 - Self-referential Structures

## Big idea

A struct can contain a **pointer to its own type**:

```c
struct tnode {                 /* the tree node */
    char *word;                /* the text            */
    int count;                 /* occurrences         */
    struct tnode *left;        /* smaller words       */
    struct tnode *right;       /* larger words        */
};
```

It can't contain a whole `struct tnode` (infinite size!) — but a POINTER to one is just an address, fixed size. This unlocks **linked data structures**: trees, lists, graphs.

This section builds a **binary search tree (BST)** counting word frequencies.

---

## The BST invariant

For every node:

```text
everything in left subtree  < node's word
everything in right subtree > node's word
```

So finding/inserting a word is a series of "go left / go right" decisions — like binary search, but on linked nodes.

---

## Inserting: addtree (recursive)

```c
struct tnode *addtree(struct tnode *p, char *w)
{
    int cond;

    if (p == NULL) {                     /* empty spot: new node here */
        p = talloc();
        p->word = mystrdup(w);
        p->count = 1;
        p->left = p->right = NULL;
    } else if ((cond = strcmp(w, p->word)) == 0)
        p->count++;                       /* already present */
    else if (cond < 0)
        p->left = addtree(p->left, w);    /* smaller: go left  */
    else
        p->right = addtree(p->right, w);  /* larger: go right  */
    return p;
}
```

Key pattern: **the function returns the (possibly new) subtree root**, and the caller stores it back: `p->left = addtree(p->left, w)`. Root usage: `root = addtree(root, word);` starting from `root = NULL`.

---

## Printing in sorted order: treeprint

```c
void treeprint(struct tnode *p)
{
    if (p != NULL) {
        treeprint(p->left);               /* all smaller first  */
        printf("%4d %s\n", p->count, p->word);
        treeprint(p->right);              /* then all larger    */
    }
}
```

This is an **in-order traversal** — left, self, right. On a BST it emits words alphabetically. The recursion mirrors the data structure's own shape.

## Memory: where do nodes come from?

Two helpers:

```c
#include <stdlib.h>

struct tnode *talloc(void)
{
    return (struct tnode *) malloc(sizeof(struct tnode));
}

char *mystrdup(const char *s)     /* copy s into safe storage */
{
    char *p = (char *) malloc(strlen(s) + 1);   /* +1 for '\0' */
    if (p != NULL)
        strcpy(p, s);
    return p;
}
```

- `malloc(n)` grabs n bytes from the heap; returns `NULL` on failure — check it!
- Why duplicate the word? `getword`'s buffer is reused each call; the tree needs its own permanent copy.
- (We call it `mystrdup` because POSIX already declares a `strdup`.)

## Performance

```text
balanced tree:  insert/search O(log n)
sorted input:   tree degenerates into a list -> O(n) per op!
```

K&R notes this worst case; balanced trees (AVL/red-black) fix it, later courses cover them.

---

## Common mistakes

```c
struct tnode { struct tnode next; };   /* WRONG: infinite size    */
p->word = w;                            /* WRONG: aliases reused buffer */
forgetting p->left = p->right = NULL;   /* garbage children -> crash */
ignoring malloc NULL return             /* crash on exhaustion     */
```

|---|---|
| Self-reference | struct holds POINTER to own type |
