# 6.2 - Structures and Functions

## Big idea

Three legal ways for functions and structures to interact:

```text
1. pass members individually
2. pass the WHOLE structure (a copy!)
3. pass a POINTER to the structure (efficient)
```

This section covers all three and introduces `->`.

---

## Returning a structure

Functions can build and return structs by value:

```c
struct point makepoint(int x, int y)
{
    struct point temp;
    temp.x = x;
    temp.y = y;
    return temp;       /* whole struct copied out */
}

struct point p = makepoint(3, 4);
```

The local `temp` dies, but its **copy** lives in `p`.

---

## Passing by value = a private copy

```c
struct point addpoint(struct point p1, struct point p2)
{
    p1.x += p2.x;      /* modifies the COPY only */
    p1.y += p2.y;
    return p1;
}
```

K&R deliberately mutates the parameter — it's safe, because the caller's struct is untouched. Call by value applies to structs just like ints (1.8).

---

## Passing a pointer: efficiency

Copying a big struct on every call is wasteful. Pass its address instead:

```c
void scale(struct point *pp, int k)
{
    (*pp).x *= k;
    (*pp).y *= k;
}
scale(&pt, 2);
```

`(*pp).x` — the parens are required: `.` binds tighter than `*`, so `*pp.x` would mean `*(pp.x)` (wrong).

---

## The arrow operator

`(*pp).x` is so common C gives it shorthand:

```c
pp->x        /* identical to (*pp).x */
```

Rule of thumb:

```text
have a struct     -> use .
have a pointer    -> use ->
```

---

## Precedence: . -> () [] are at the TOP

These four bind tightest and associate left-to-right:

```c
++p->len       means  ++(p->len)      increment the member
*p->str        means  *(p->str)       first char str points to
*p->str++      means  *(p->str++)     fetch char, then advance str
(*p->str)++    increments the char itself
*p++->str      fetch char, then advance p
```

Worth memorizing — this exact list is in the book.

---

## When to choose which

| Situation | Choice |
|---|---|
| small struct, function shouldn't modify it | pass by value |
| function must modify the caller's struct | pass pointer |
| struct is large | pass pointer (avoid copy cost) |
| building a fresh value | return by value |

---

## Summary table

| Concept | Syntax |
|---|---|
| Return struct | `struct point f(...) { ...; return temp; }` |
| Pass by value | `f(pt)` — callee gets a copy |
| Pass by pointer | `f(&pt)` — callee shares the original |
| Deref member | `(*pp).x` — parens mandatory |
| Arrow | `pp->x` |
| Top precedence | `()` `[]` `.` `->` |
| `++p->len` | increments len, not p |
