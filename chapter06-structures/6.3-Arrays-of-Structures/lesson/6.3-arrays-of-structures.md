# 6.3 - Arrays of Structures

## Big idea

Need a table where each row has multiple typed columns? Don't make parallel arrays:

```c
char *word[NKEYS];     /* fragile: two arrays  */
int   count[NKEYS];    /* that must stay in sync */
```

Make ONE array of structures:

```c
struct key {
    char *word;
    int count;
} keytab[NKEYS];
```

Each `keytab[i]` is a complete row.

---

## Initializing an array of structs

```c
struct key keytab[] = {
    { "auto",  0 },
    { "break", 0 },
    { "case",  0 },
    /* ... alphabetical! ... */
    { "while", 0 }
};
```

Inner braces per row. K&R notes they can be omitted when initializers are simple values, but keep them — the compiler warns without them.

---

## Computing the array size: the sizeof trick

Let the compiler count rows:

```c
#define NKEYS (sizeof keytab / sizeof keytab[0])
```

- `sizeof keytab` = total bytes
- `sizeof keytab[0]` = bytes per row
- division = number of rows

Add a keyword later? NKEYS updates itself. K&R also shows `sizeof(struct key)` — same idea.

`sizeof` yields type `size_t`; print with `%zu`.

---

## The keyword counter (book program)

Count C keywords in input:

```text
for each word from input:
    binary-search it in keytab
    if found: keytab[i].count++
finally print every keytab row with count > 0
```

Members access like: `keytab[mid].word`, `keytab[i].count` — subscript first, then dot.

---

## Binary search over struct rows

Works because keytab is **sorted by word**:

```c
int binsearch(char *word, struct key tab[], int n)
{
    int cond, low = 0, high = n - 1, mid;

    while (low <= high) {
        mid = (low + high) / 2;
        if ((cond = strcmp(word, tab[mid].word)) < 0)
            high = mid - 1;
        else if (cond > 0)
            low = mid + 1;
        else
            return mid;
    }
    return -1;
}
```

O(log n) vs linear scan's O(n). The comparison key is the `.word` member.

---

## getword (support routine)

Reads the next "word" (letter then letters/digits) from input:

```text
skip whitespace
if first char isn't a letter: return it as-is (handles punctuation)
else collect alphanumerics into word[]
```

Uses `isalpha`, `isalnum`, `isspace` from `<ctype.h>` and needs a one-character pushback (`ungetch` from Ch4 or `ungetc`).

---

## Padding warning

A struct's size may exceed the sum of its members — alignment padding. ALWAYS use `sizeof`, never hand-added member sizes.

## Summary table

| Concept | Syntax |
|---|---|
| Array of structs | `struct key keytab[NKEYS];` |
| Init rows | `{ {"auto",0}, {"break",0} }` |
| Row count | `sizeof keytab / sizeof keytab[0]` |
| Access | `keytab[i].word`, `keytab[i].count` |
| Search sorted rows | binary search on the key member, O(log n) |
| sizeof type | `size_t`, print `%zu` |
| Padding | struct size >= sum of members |
