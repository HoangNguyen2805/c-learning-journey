# 8.2 - Low Level I/O - Read and Write

## Big idea

ALL input and output on UNIX funnels through two system calls:

```c
int n_read    = read(int fd, char *buf, int n);
int n_written = write(int fd, char *buf, int n);
```

- first arg: file descriptor
- second: YOUR buffer where bytes go/come from
- third: how many bytes you want moved
- return: bytes actually transferred (may be less!), 0 = end of file (read), negative = error

---

## The buffer size is yours to choose

```text
n = 1                     one char per syscall - unbuffered, slow
n = 1024 / 4096 (BUFSIZ)  disk-block sized - efficient
```

Any size works correctly; larger sizes mean fewer (expensive) system calls.

---

## The whole of cat, in the raw

```c
#include "syscalls.h"     /* K&R's stand-in; today: <unistd.h> */

main()   /* copy input to output */
{
    char buf[BUFSIZ];
    int n;

    while ((n = read(0, buf, BUFSIZ)) > 0)
        write(1, buf, n);
    return 0;
}
```

**Crucial detail**: write `n` bytes — the count READ — not BUFSIZ. The last chunk is usually partial.

---

## Building getchar from read

Unbuffered version:

```c
int getchar(void)     /* unbuffered single character of input */
{
    char c;

    return (read(0, &c, 1) == 1) ? (unsigned char) c : EOF;
}
```

`(unsigned char)` prevents sign-extension making legit chars look like EOF.

Buffered version — read a chunk, dole it out:

```c
int getchar(void)     /* simple buffered version */
{
    static char buf[BUFSIZ];
    static char *bufp = buf;
    static int n = 0;

    if (n == 0) {                       /* buffer is empty */
        n = read(0, buf, sizeof buf);
        bufp = buf;
    }
    return (--n >= 0) ? (unsigned char) *bufp++ : EOF;
}
```

`static` locals persist between calls — the buffer survives. This is a miniature of what stdio does inside FILE.

---

## Records are a fiction

To the system calls, a "line" doesn't exist — just bytes. Newlines are ordinary bytes; any structure (lines, records) is imposed by programs, not the OS.

---

## Summary table

| Concept | Fact |
|---|---|
| read(fd,buf,n) | up to n bytes into buf; returns count |
| return 0 | end of file |
| return < 0 | error |
| write(fd,buf,n) | returns count written; != n means error |
| BUFSIZ | efficient chunk size (stdio.h) |
| Partial last chunk | write the READ count, not the buffer size |
| Buffered getchar | static buffer + pointer + count |
| unsigned char cast | keep 0xFF from becoming EOF |
