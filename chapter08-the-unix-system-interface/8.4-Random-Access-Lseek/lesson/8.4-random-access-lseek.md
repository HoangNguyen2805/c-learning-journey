# 8.4 - Random Access - Lseek

## Big idea

Reads and writes are normally **sequential**: each one continues where the last stopped. `lseek` moves the file position ANYWHERE, without reading or writing:

```c
long lseek(int fd, long offset, int origin);
```

The file becomes a big array of bytes you can jump around in.

---

## The origin argument

Position becomes `offset` measured from `origin`:

```text
origin 0  (SEEK_SET)   from the beginning
origin 1  (SEEK_CUR)   from the current position
origin 2  (SEEK_END)   from the end of file
```

Examples:

```c
lseek(fd, 0L, 2);      /* jump to end - ready to append   */
lseek(fd, 0L, 0);      /* rewind to the beginning         */
lseek(fd, -1L, 2);     /* position at the LAST byte       */
lseek(fd, 100L, 0);    /* absolute byte 100               */
```

Returns the new position (long), or **-1 on error**.

---

## The book's get: random-record reader

```c
#include "syscalls.h"

/* get: read n bytes from position pos */
int get(int fd, long pos, char *buf, int n)
{
    if (lseek(fd, pos, 0) >= 0)       /* get to pos */
        return read(fd, buf, n);
    else
        return -1;
}
```

Seek, then read — the essence of every database and every file format with an index: compute where a record lives, jump, read exactly it.

---

## Fixed-size records = O(1) access

If every record is RECSIZE bytes, record k lives at byte `(long)k * RECSIZE`:

```c
lseek(fd, (long)k * RECSIZE, 0);
read(fd, buf, RECSIZE);
```

No scanning past k-1 records — direct arithmetic. This is an ARRAY on disk.

---

## stdio's cousin

The library equivalent (Chapter 7 world) is `fseek(fp, offset, origin)` with the same three origins — and `ftell(fp)` reports the position. K&R Exercise 8-4 asks you to implement fseek over lseek, minding the buffer.

---

## Gotchas

- offset is a **long** — write `0L`, cast products: `(long)k * RECSIZE` (int multiply could overflow first!)
- seeking past EOF is legal; writing there leaves a "hole" (reads as zeros)
- mixing buffered stdio and raw lseek on the same file desynchronizes them — flush first (8.5 shows why)

---

## Summary table

| Call | Effect |
|---|---|
| `lseek(fd, 0L, 0)` | rewind |
| `lseek(fd, 0L, 2)` | to end (append point) |
| `lseek(fd, n, 1)` | skip forward n |
| `lseek(fd, -n, 2)` | n bytes before end |
| return | new position, or -1 |
| record k | seek to `(long)k * RECSIZE` |
| stdio twins | fseek / ftell |
