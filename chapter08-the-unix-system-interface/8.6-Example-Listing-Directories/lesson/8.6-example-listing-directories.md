# 8.6 - Example: Listing Directories

## Big idea

Build `fsize`: a program that prints the size of files — and when the file is a **directory**, recurses through everything inside. Along the way: how UNIX stores file metadata, and the directory-walking pattern every file tool uses.

---

## Inodes: where file info really lives

A directory doesn't contain files — it contains **(name, inode number) pairs**. The inode holds everything else: size, permissions, timestamps, type. Getting metadata:

```c
#include <sys/types.h>
#include <sys/stat.h>

struct stat stbuf;
stat(name, &stbuf);      /* fills stbuf with name's inode info; -1 on error */
```

Key members of `struct stat`:

```text
st_mode    type & permissions
st_size    file size in bytes (long)
st_uid     owner
st_mtime   last modification time
...
```

Type test via mask (6.9 again!):

```c
if ((stbuf.st_mode & S_IFMT) == S_IFDIR)     /* it's a directory */
```

---

## The portable directory API

Directory formats vary by system, so K&R defines a minimal interface (identical in spirit to POSIX `<dirent.h>`):

```c
typedef struct {          /* portable directory entry */
    long ino;             /* inode number             */
    char name[NAME_MAX+1];/* name + '\0' terminator   */
} Dirent;

typedef struct {          /* minimal DIR */
    int fd;
    Dirent d;
} DIR;

DIR *opendir(char *dirname);
Dirent *readdir(DIR *dfd);      /* next entry, or NULL */
void closedir(DIR *dfd);
```

Usage pattern — the standard walk:

```c
DIR *dfd = opendir(dir);
while ((dp = readdir(dfd)) != NULL) {
    ... use dp->name ...
}
closedir(dfd);
```

## fsize and dirwalk: mutual recursion

```c
void fsize(char *name)           /* print size of one name */
{
    struct stat stbuf;

    if (stat(name, &stbuf) == -1) {
        fprintf(stderr, "fsize: can't access %s\n", name);
        return;
    }
    if ((stbuf.st_mode & S_IFMT) == S_IFDIR)
        dirwalk(name, fsize);            /* recurse into directory */
    printf("%8ld %s\n", stbuf.st_size, name);
}
```

```c
#define MAX_PATH 1024

void dirwalk(char *dir, void (*fcn)(char *))   /* apply fcn to files in dir */
{
    char name[MAX_PATH];
    Dirent *dp;
    DIR *dfd;

    if ((dfd = opendir(dir)) == NULL) {
        fprintf(stderr, "dirwalk: can't open %s\n", dir);
        return;
    }
    while ((dp = readdir(dfd)) != NULL) {
        if (strcmp(dp->name, ".") == 0
         || strcmp(dp->name, "..") == 0)
            continue;                    /* skip self and parent */
        if (strlen(dir)+strlen(dp->name)+2 > sizeof(name))
            fprintf(stderr, "dirwalk: name %s/%s too long\n",
                    dir, dp->name);
        else {
            sprintf(name, "%s/%s", dir, dp->name);
            (*fcn)(name);                /* callback! */
        }
    }
    closedir(dfd);
}
```

Design gems:

1. **Mutual recursion**: fsize → dirwalk → fsize... matching the file tree's own recursive shape (like dcl/dirdcl in 5.12!)
2. **Function pointer parameter**: dirwalk applies ANY `void f(char*)` — it's a directory `map()`. (5.11 pays off.)
3. **Skip "." and ".."**: every directory lists itself and its parent — recursing into them loops forever.
4. **Path length check BEFORE sprintf** — no overflow.

(Heads-up: the freebooks transcription of this code drops an `== 0` on one strcmp — the version above is correct.)

## Modern usage

On Linux today, `<dirent.h>` gives you `opendir/readdir/closedir` with `struct dirent` (member `d_name`) directly — same shapes, ready-made. K&R's section then implements the API itself over raw syscalls; the interface is what matters.

## Summary table

| Concept | Meaning |
|---|---|
| inode | per-file metadata record |
| directory | list of (name, inode) pairs |
| stat(name, &st) | fetch metadata; -1 on error |
| st_mode & S_IFMT | extract the type bits |
| S_IFDIR | the directory type |
| opendir/readdir/closedir | the walking API |
| skip "." ".." | prevents infinite recursion |
| dirwalk(dir, fcn) | map a callback over entries |
| fsize <-> dirwalk | mutual recursion over the tree |
