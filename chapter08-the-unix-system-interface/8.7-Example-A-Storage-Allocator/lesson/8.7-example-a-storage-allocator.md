# 8.7 - Example: A Storage Allocator

## Big idea

The grand finale of K&R: implement **malloc and free themselves**. The design: a **circular free list** of variable-sized blocks, carved from memory obtained from the OS.

```text
free list:  [block 120 units] -> [block 8 units] -> [block 500 units] -+
                 ^                                                     |
                 +-----------------------------------------------------+
```

- blocks are kept **in order of increasing address** (crucial for merging!)
- malloc searches **first fit**: first block big enough
- free re-inserts a block and **coalesces** with adjacent neighbors

---

## The Header: alignment via union

Every block starts with a header holding its size and the next free block:

```c
typedef long Align;              /* for alignment to long boundary */

union header {                   /* block header */
    struct {
        union header *ptr;       /* next block if on free list */
        unsigned size;           /* size of this block         */
    } s;
    Align x;                     /* force alignment of blocks  */
};

typedef union header Header;
```

The `Align x` member is never used — it only forces each header (and thus each block) to the most restrictive alignment (6.8's honest union use!). **Sizes are measured in header-sized units.** The pointer returned to the user points just PAST the header.

```text
[ Header | user space ........ ]
           ^-- malloc returns this
```

---

## malloc: first-fit search

```c
static Header base;              /* empty list to get started */
static Header *freep = NULL;     /* start of free list        */

void *malloc(unsigned nbytes)
{
    Header *p, *prevp;
    Header *morecore(unsigned);
    unsigned nunits;

    nunits = (nbytes+sizeof(Header)-1)/sizeof(Header) + 1;
    if ((prevp = freep) == NULL) {        /* no free list yet */
        base.s.ptr = freep = prevp = &base;
        base.s.size = 0;
    }
    for (p = prevp->s.ptr; ; prevp = p, p = p->s.ptr) {
        if (p->s.size >= nunits) {        /* big enough */
            if (p->s.size == nunits)      /* exactly    */
                prevp->s.ptr = p->s.ptr;
            else {                        /* allocate tail end */
                p->s.size -= nunits;
                p += p->s.size;
                p->s.size = nunits;
            }
            freep = prevp;
            return (void *)(p+1);
        }
        if (p == freep)                   /* wrapped around free list */
            if ((p = morecore(nunits)) == NULL)
                return NULL;              /* none left */
    }
}
```

Decode the pieces:

- **nunits**: bytes rounded UP to whole units, +1 for the header itself. The `+sizeof(Header)-1` before dividing is the standard round-up idiom.
- **first call**: builds a degenerate list — base points to itself, size 0.
- **exact fit**: unlink the block (`prevp->s.ptr = p->s.ptr`).
- **too big**: shrink the block and hand out its TAIL — the front stays listed, so no relinking needed. Slick!
- **wrap-around** (`p == freep`): searched everything; ask the OS via morecore.
- `return (p+1)`: pointer arithmetic — one Header past the header = user space.

## morecore: refilling the arena

```c
#define NALLOC 1024      /* minimum #units to request */

static Header *morecore(unsigned nu)
{
    char *cp, *sbrk(int);
    Header *up;

    if (nu < NALLOC)
        nu = NALLOC;
    cp = sbrk(nu * sizeof(Header));
    if (cp == (char *) -1)       /* no space at all */
        return NULL;
    up = (Header *) cp;
    up->s.size = nu;
    free((void *)(up+1));        /* insert into arena via free! */
    return freep;
}
```

- OS memory comes from `sbrk(n)` — n more bytes; returns **(char\*)-1** on failure (not NULL — historical wart, hence the cast).
- Asks for at least NALLOC units — syscalls are expensive; get a big slab, chop it up locally (the 8.2 buffering lesson, again).
- Cleverest line: it inserts the new memory by **calling free on it** — reusing the insertion+coalescing logic instead of duplicating it.

---

## free: insert + coalesce

```c
void free(void *ap)
{
    Header *bp, *p;

    bp = (Header *)ap - 1;       /* point to block header */
    for (p = freep; !(bp > p && bp < p->s.ptr); p = p->s.ptr)
        if (p >= p->s.ptr && (bp > p || bp < p->s.ptr))
            break;               /* freed block at start or end of arena */

    if (bp + bp->s.size == p->s.ptr) {   /* join to upper neighbor */
        bp->s.size += p->s.ptr->s.size;
        bp->s.ptr = p->s.ptr->s.ptr;
    } else
        bp->s.ptr = p->s.ptr;
    if (p + p->s.size == bp) {           /* join to lower neighbor */
        p->s.size += bp->s.size;
        p->s.ptr = bp->s.ptr;
    } else
        p->s.ptr = bp;
    freep = p;
}
```

- `(Header*)ap - 1`: step BACK over the header the user never saw.
- The scan finds the address-ordered insertion spot: loop until `p < bp < p->s.ptr`. The inner `if` handles wrap-around — bp beyond the highest block or below the lowest.
- **Coalescing**: if `bp + bp->s.size == p->s.ptr`, the freed block touches the next one — merge them (add sizes, splice pointers). Then the same test against the previous block `p`. Adjacent frees fuse into big blocks — fighting **fragmentation**.

(Note: the freebooks PDF transcription garbles a few identifiers here — `moreroce`, `sizeof(header)`, `bp->size` — the versions above are the corrected, working code.)

## Analysis

```text
malloc: O(F) scan of free list (F = free blocks); first fit
free:   O(F) scan for the address-ordered spot; O(1) merge
fragmentation: coalescing + address order keep neighbors mergeable
alternatives:  best-fit, segregated lists, buddy allocators (later courses)
```

## Summary table

| Piece | Job |
|---|---|
| Header union | size + next, alignment-forced |
| units | sizes counted in sizeof(Header) chunks |
| nunits formula | round up + 1 for header |
| free list | circular, address-ordered |
| first fit | take first big-enough block's tail |
| freep | roving start pointer |
| morecore | sbrk >= NALLOC units, insert via free |
| sbrk failure | (char*)-1, not NULL |
| free | address-ordered insert + coalesce both sides |
| user pointer | header + 1 |
