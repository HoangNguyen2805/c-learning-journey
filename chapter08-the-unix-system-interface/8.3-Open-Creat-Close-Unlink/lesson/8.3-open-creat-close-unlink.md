# 8.3 - Open, Creat, Close, Unlink

## Big idea

Besides the pre-opened 0/1/2, files must be opened explicitly. The syscalls:

```c
int open(char *name, int flags, int perms);
int creat(char *name, int perms);
close(int fd);
unlink(char *name);
```

These are what `fopen` and `remove` call underneath.

---

## open

```c
#include <fcntl.h>

int fd;
fd = open(name, O_RDONLY, 0);
```

Flags (from `<fcntl.h>`):

```text
O_RDONLY   read only
O_WRONLY   write only
O_RDWR     both
```

- returns a descriptor, or **-1 on error** (note: -1, not NULL — it's an int!)
- opening a nonexistent file with plain open FAILS

Modern additions (useful now, standard practice): `O_CREAT` (create if missing), `O_TRUNC` (truncate), `O_APPEND`.

---

## creat

```c
fd = creat(name, perms);
```

- creates the file (or **truncates an existing one to zero length**)
- perms example: `0666` — read+write for owner, group, others (octal! 6.9 pays off)

```text
#define PERMS 0666     /* RW for owner, group, others */
```

`creat(name, PERMS)` ≡ `open(name, O_WRONLY|O_CREAT|O_TRUNC, PERMS)`.

---

## The book's cp program

```c
#include <stdio.h>
#include <fcntl.h>
#include "syscalls.h"
#define PERMS 0666

void error(char *, ...);

main(int argc, char *argv[])     /* cp: copy f1 to f2 */
{
    int f1, f2, n;
    char buf[BUFSIZ];

    if (argc != 3)
        error("Usage: cp from to");
    if ((f1 = open(argv[1], O_RDONLY, 0)) == -1)
        error("cp: can't open %s", argv[1]);
    if ((f2 = creat(argv[2], PERMS)) == -1)
        error("cp: can't create %s, mode %03o", argv[2], PERMS);
    while ((n = read(f1, buf, BUFSIZ)) > 0)
        if (write(f2, buf, n) != n)
            error("cp: write error on file %s", argv[2]);
    return 0;
}
```

Notes:

- checks `== -1` on both opens
- checks `write(...) != n` — a genuine write-error test
- files close automatically at exit (but real code closes explicitly)

## error: variadic diagnostics (7.3 + 7.6 combined!)

```c
#include <stdarg.h>

void error(char *fmt, ...)       /* print an error message and die */
{
    va_list args;

    va_start(args, fmt);
    fprintf(stderr, "error: ");
    vfprintf(stderr, fmt, args);
    fprintf(stderr, "\n");
    va_end(args);
    exit(1);
}
```

## close and unlink

```c
close(fd);       /* break the fd<->file connection; frees the slot   */
unlink(name);    /* remove the name from the filesystem (= remove()) */
```

There's a limit (historically ~20, now much higher) on simultaneous open files — long-running programs must close what they're done with. exit() closes everything.

## Summary table

| Call | Purpose | Failure |
|---|---|---|
| `open(name, O_RDONLY, 0)` | open existing | -1 |
| `creat(name, 0666)` | create/truncate | -1 |
| `close(fd)` | release descriptor | -1 |
| `unlink(name)` | delete filename | -1 |
| PERMS 0666 | rw-rw-rw- (octal) | |
| write check | `write(...) != n` means trouble | |
| error(fmt, ...) | stderr + exit(1), via vfprintf | |
