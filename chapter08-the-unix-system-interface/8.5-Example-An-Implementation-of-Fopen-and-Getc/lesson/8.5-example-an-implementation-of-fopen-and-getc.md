# 8.5 - Example: An Implementation of Fopen and Getc

## Big idea

The curtain drops: this section builds a working chunk of the standard library — `fopen` and `getc` — out of Chapter 8's raw syscalls. You finally see what's inside a `FILE`.

---

## What a FILE really is

```c
#define NULL      0
#define EOF       (-1)
#define BUFSIZ    1024
#define OPEN_MAX  20    /* max #files open at once */

typedef struct _iobuf {
    int  cnt;       /* characters left in buffer      */
    char *ptr;      /* next character position        */
    char *base;     /* location of buffer             */
    int  flag;      /* mode of file access            */
    int  fd;        /* file descriptor                */
} FILE;

extern FILE _iob[OPEN_MAX];

#define stdin  (&_iob[0])
#define stdout (&_iob[1])
#define stderr (&_iob[2])
```

A FILE = **a buffer + bookkeeping + the underlying fd**. stdin/stdout/stderr are just the first three slots of a fixed array.

The flag field is a bit set (6.9 in the wild!):

```c
enum _flags {
    _READ  = 01,    /* file open for reading      */
    _WRITE = 02,    /* file open for writing      */
    _UNBUF = 04,    /* file is unbuffered         */
    _EOF   = 010,   /* EOF has occurred           */
    _ERR   = 020    /* error occurred             */
};
```

## getc and putc are macros

```c
#define getc(p)  (--(p)->cnt >= 0 \
                   ? (unsigned char) *(p)->ptr++ : _fillbuf(p))

#define putc(x,p) (--(p)->cnt >= 0 \
                   ? *(p)->ptr++ = (x) : _flushbuf((x),p))

#define getchar()   getc(stdin)
#define putchar(x)  putc((x), stdout)
```

The fast path is pure pointer arithmetic — decrement a count, fetch through a pointer. Only when the buffer runs dry does `_fillbuf` do a real `read()`. That's the whole performance secret of stdio.

## fopen

```c
FILE *fopen(char *name, char *mode)
{
    int fd;
    FILE *fp;

    if (*mode != 'r' && *mode != 'w' && *mode != 'a')
        return NULL;
    for (fp = _iob; fp < _iob + OPEN_MAX; fp++)
        if ((fp->flag & (_READ | _WRITE)) == 0)
            break;                    /* found free slot */
    if (fp >= _iob + OPEN_MAX)        /* no free slots   */
        return NULL;

    if (*mode == 'w')
        fd = creat(name, PERMS);
    else if (*mode == 'a') {
        if ((fd = open(name, O_WRONLY, 0)) == -1)
            fd = creat(name, PERMS);
        lseek(fd, 0L, 2);
    } else
        fd = open(name, O_RDONLY, 0);
    if (fd == -1)                     /* couldn't access name */
        return NULL;

    fp->fd = fd;
    fp->cnt = 0;
    fp->base = NULL;                  /* buffer allocated LAZILY */
    fp->flag = (*mode == 'r') ? _READ : _WRITE;
    return fp;
}
```

Three jobs: find a free FILE slot (linear scan of `_iob`), get an fd with the right syscall per mode ("a" = open-or-create then seek to end — 8.4!), initialize the bookkeeping. Buffer allocation waits until first use.

## _fillbuf

```c
int _fillbuf(FILE *fp)
{
    int bufsize;

    if ((fp->flag & (_READ|_EOF|_ERR)) != _READ)
        return EOF;
    bufsize = (fp->flag & _UNBUF) ? 1 : BUFSIZ;
    if (fp->base == NULL)             /* no buffer yet */
        if ((fp->base = (char *) malloc(bufsize)) == NULL)
            return EOF;               /* can't get buffer */
    fp->ptr = fp->base;
    fp->cnt = read(fp->fd, fp->ptr, bufsize);
    if (--fp->cnt < 0) {
        if (fp->cnt == -1)
            fp->flag |= _EOF;
        else
            fp->flag |= _ERR;
        fp->cnt = 0;
        return EOF;
    }
    return (unsigned char) *fp->ptr++;
}
```

Called when getc's count hits -1: allocate the buffer on first need, `read()` a chunk, reset ptr/cnt, hand back the first character. EOF/error set flag bits — mirroring feof/ferror from 7.6!

```c
#define feof(p)    (((p)->flag & _EOF) != 0)
#define ferror(p)  (((p)->flag & _ERR) != 0)
#define fileno(p)  ((p)->fd)
```

## Summary table

| Piece | Role |
|---|---|
| FILE | cnt, ptr, base, flag, fd |
| _iob[OPEN_MAX] | all the FILEs there are |
| stdin/out/err | &_iob[0/1/2] |
| getc | macro: fast path `--cnt >= 0` |
| _fillbuf | slow path: malloc once + read() |
| fopen | free slot + right syscall + init |
| "a" mode | open/creat then lseek 0L,2 |
| flag bits | _READ _WRITE _UNBUF _EOF _ERR |
